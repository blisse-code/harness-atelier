### Agency rules

- **Per client, never studio-wide.** Tokens, components and ux-context belong to this client's project. Bootstrap order at the start of the design track: a previous project for the same client → the client's existing system → the studio base kit → fresh. Log which in `system/system-log.md`. <!-- design -->
- **Name who owns the edges.** `context/scope.md` records which other teams touch this initiative, what they own and what happens at each handoff.
- **Client material lives in the client's shared drive, linked, not copied in.** Record links in `context/brief.md`.
- **Out-of-order feedback is normal.** Round-1 comments arriving during round 3 are reconciled into the current round through `feedback-to-changes`, not treated as invalidating later work.
- **Several people, one repo.** Push routine updates directly; on a conflict in an append-only record keep both sides; run the `reconciler` agent after a pull, before the lead reviews.
